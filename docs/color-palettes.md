# 配色方案

常规设置提供四种配色，均覆盖首页、节点详情、菜单、状态和图表，沿用独立的字体设置。

| 方案 | 方向 |
|---|---|
| 中性白 | 原 Kumo。中性灰层级与蓝色交互，清晰利落，作为新配置的默认方案。 |
| 柔暖色 | 原 A\。暖纸色与陶土橙，搭配灰蓝、鼠尾草绿及柔和的图表辅助色。 |
| 科技蓝 | 参考 IBM Carbon 的主蓝与交互层级，采用浅蓝底和深海军蓝暗色表面。 |
| 薄荷绿 | 参考 Supabase 的品牌绿与功能色原则，采用淡绿底与深绿暗色表面。 |

## 柔暖色的依据

参考 [Anthropic 官方公开品牌色](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)：炭黑 `#141413`、暖白 `#faf9f5`、中灰 `#b0aea5`、浅灰 `#e8e6dc`，以及橙 `#d97757`、蓝 `#6a9bcc`、绿 `#788c5d`。

在这些主色上为监控界面延展表面层级和暗色模式；不是把品牌资料当作完整的产品界面规范。亮色采用暖灰纸底 `#f3f1eb` 与暖白卡片 `#faf9f5`，暗色采用暖炭底 `#1c1b19` 与深暖灰卡片 `#26241f`。其他边框、状态背景和图表辅助色由本主题设计。

陶土橙用于交互重点，灰蓝和鼠尾草绿帮助区分图表。状态成功、警告、错误保持独立语义。中灰主要用于分隔和弱化元素，正文与数值使用更深或更亮的文字色。

配色解析器会根据实际表面调整文字和图表数值颜色，确保对比度；因此浅底上的文字橙可能比品牌原色更深。图表颜色在两个模式中保持相同类别含义。字体继续由“字体方案”控制。

## 科技蓝与薄荷绿的依据

[IBM Carbon 色彩规范](https://www.carbondesignsystem.com/building-blocks/foundations/color/tokens)提供 Blue 60 `#0f62fe` 等交互色和分层表面规则。科技蓝保留蓝色交互及独立状态色，并为本主题延展浅蓝页面底 `#edf5ff`、深海军蓝底 `#101a30` 和蓝灰边框；这些带色表面属于本主题的适配。

[Supabase 品牌规范](https://supabase.com/brand)给出品牌绿 `#3ecf8e`；[功能色规范](https://supabase.com/design-system/docs/color-usage)区分品牌色和用于文字、选中态、焦点的功能色。薄荷绿在亮色中使用更深的绿以保证文字可读，暗色交互使用品牌绿，并延展淡绿底 `#f0f8f3`、深绿底 `#101c17`。

## 名称与兼容

四个显示名称按顺序为 `中性白 / 柔暖色 / 科技蓝 / 薄荷绿`，内部标识为 `Kumo / Anthropic / Carbon / Supabase`。此前保存的 `Kumo`、`A\` 仍能识别为前两款；更早已删除的 Warm/Red/Blue/Green 等值仍回退中性白，不恢复旧配色。

开发时可用 `VITE_COLOR_PRESET=Carbon` 或 `Supabase` 预览新方案；该覆盖不进入生产安装包。
